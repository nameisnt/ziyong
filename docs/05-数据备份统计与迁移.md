# 数据、备份、统计与迁移

本文说明新增 App 如何接入数据持久化、备份、统计和当前聊天清理。

## 聊天作用域数据

创作内容通常按当前聊天保存。内置 store 使用 `useChatScopedDomain` 管理：

- 当前 scope key。
- zod schema 校验。
- 当前聊天数据读取和重置。
- 从 `extension_settings` 重新水合。

新增内容型 App 推荐复用同样模式。这样它可以自然接入当前聊天清理、备份和统计。

## backupDomains

`backupDomains` 用于把 App 数据加入整包备份。

```ts
backupDomains: [{
  key: 'my-app',
  exportData: currentScopeKey => ({
    currentScopeKey,
    scopes: useMyAppStore().data.scopes,
  }),
  importData: data => useMyAppStore().importBackup(data),
  rehydrateFromSettings: () => useMyAppStore().rehydrateFromSettings(),
}]
```

备份流程：

- `buildPhoneBackup()` 调用所有注册的 `exportData`。
- 数据写入 `backup.data.domains[domain.key]`。
- `applyPhoneBackup()` 按注册域调用 `importData`。
- 导入完成后设置页会调用注册的 `rehydrateFromSettings`。

兼容性：

- 备份 schema 仍保留旧字段兼容。
- 新数据推荐统一进入 `data.domains`。

## contentStatsProvider

`contentStatsProvider(currentScopeKey)` 返回当前 App 的统计贡献。

```ts
contentStatsProvider: currentScopeKey => ({
  current: {
    scopeCount: 1,
    collections: 1,
    items: 3,
    chars: 1200,
    averageChars: 400,
    latestUpdatedAt: '2026-01-01T00:00:00.000Z',
  },
  domain: {
    id: 'my-app',
    label: '我的应用',
    collectionLabel: '分组',
    itemLabel: '项',
    scopeCount: 5,
    collections: 8,
    items: 30,
    chars: 12000,
    averageChars: 400,
    latestUpdatedAt: '2026-01-01T00:00:00.000Z',
  },
  overview: {
    scopeCount: 5,
    collections: 8,
    items: 30,
    chars: 12000,
    averageChars: 400,
    latestUpdatedAt: '2026-01-01T00:00:00.000Z',
  },
  scopeKeys: [currentScopeKey],
  warnings: [],
})
```

统计页和设置页会通过 `getRegisteredPhoneContentStats` 自动聚合。

## resetCurrentScope

如果 App 有当前聊天数据，应该注册：

```ts
resetCurrentScope: () => useMyAppStore().resetCurrentScope()
```

设置页执行“清理当前聊天数据”时会调用所有注册的 reset handler。

## favoriteProvider

收藏数据不需要单独全局聚合 store。每个 App 返回自己的收藏项即可。

收藏项建议提供：

- `exists`：内容是否仍存在。
- `open`：如何跳转到详情。
- `removeFavorite`：如何取消收藏。

这样收藏页不需要知道业务 store。

## referenceProvider

引用来源树用于生成时选择其他 App 的内容作为参考。新增 App 提供树结构后，引用选择器会自动展示。

树节点分两类：

- `branch`：分组节点。
- `leaf`：具体可引用内容。

`leaf.item` 最终会被 `formatGenerationReferences` 转为提示词文本。

## 迁移建议

新增 App 时建议按这个顺序接入：

1. 先注册最小 `component`，确认能在首页打开。
2. 接入 store 和 `backupDomains`。
3. 接入 `promptDefinitions` 和 `generationProvider`。
4. 接入 `favoriteProvider`、`referenceProvider`、`contentStatsProvider`。
5. 最后补 `resetCurrentScope` 和导入后的 `rehydrateFromSettings`。

这样每一步都能独立验证，出问题时边界清楚。
