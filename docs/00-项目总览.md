# 功能性阅读器插件总览

功能性阅读器是一个运行在 SillyTavern 扩展环境中的手机式创作面板。它把总结、日记、番外、论坛、小剧场、书信、收藏、提示词、统计、聊天档案、阅读聊天、八股去除和设置等能力组织成 App，并通过统一的 App 注册表接入首页、导航、备份、统计、收藏、引用来源和生成管线。

当前代码已经从硬编码 App 列表改为插件式注册。新增 App 的推荐入口是 `src/apps/<app-id>/index.ts`，默认导出
`definePhoneApp(...)` 创建的模块。`src/data/apps.ts` 会注册内置 App，并通过 `import.meta.glob('../apps/*/index.ts')`
自动发现新增模块。

## 核心入口

- `src/core/appRegistry.ts`：App 注册表与能力聚合入口。
- `src/core/appLayout.ts`：首页布局和 App 定义读取 helper，只依赖注册表，供 store 层复用。
- `src/data/apps.ts`：注册内置模块，自动发现 `src/apps/*/index.ts`，由生命周期入口显式初始化。
- `src/components/PhoneOverlay.vue`：手机壳、首页、导航栈与动态 App 组件渲染。
- `src/apps/builtin.ts`：内置 App 的注册清单。
- `src/apps/README.md`：新增 App 的最小注册示例。
- `docs/07-当前代码与UI复用审计及设计要求.md`：当前代码与 UI 复用现状、问题和设计硬要求的唯一总则。
- `docs/archive/README.md`：已完成方案的历史索引；归档内容只用于追溯，不属于当前待办。

## 当前内置 App

- 总结：按聊天楼层生成阶段总结。
- 日记：以角色视角生成日记，也支持读日记后的反应。
- 番外：章节式衍生创作，支持章节总结和类型提示词。
- 论坛：生成论坛帖子、回帖和楼中楼。
- 小剧场：生成短篇互动，支持 Markdown 和前端网页片段渲染。
- 书信：生成正式信件、短信、邮件、便签等往来内容。
- 收藏：聚合各创作 App 的收藏内容。
- 提示词：管理 App 默认提示词、特殊提示词、类型提示词和快速短语。
- 统计：统计当前聊天和全局内容规模。
- 聊天档案：按角色卡和聊天索引已保存的手机内容，历史聊天第一版只读。
- 阅读聊天：读取并转换当前聊天，支持正则预设。
- 八股去除：检测并替换常见生成腔表达。
- 设置：主题、壁纸、字体、生成来源、备份导入导出等。

## 插件式注册已经覆盖的能力

`PhoneAppModule` 当前可以声明这些能力：

- `component`：App 主组件。
- `generationProvider`：生成 action 与 adapter。
- `promptDefinitions`：App 默认提示词与输出格式预览。
- `specialPromptDefinitions`：特殊提示词。
- `typePromptDomains`：类型提示词域和默认类型提示词。
- `backupDomains`：备份导入导出域。
- `contentStatsProvider`：统计贡献。
- `favoriteProvider`：收藏聚合贡献。
- `referenceProvider`：生成引用来源树。
- `resetCurrentScope`：清空当前聊天数据的处理函数。

这些能力都由注册表统一收集。新增 App 只要把能力挂到自己的模块上，就能被对应的系统页面消费。

## 数据范围

插件数据分为两类：

- 全局设置：主题、提示词、八股规则、阅读器设置、恢复记录等。
- 聊天作用域数据：总结、日记、番外、论坛、小剧场、书信等创作内容。

聊天作用域通常通过 `useChatScopedDomain` 按当前聊天 scope 保存，备份时再由 `backupDomains` 聚合。
