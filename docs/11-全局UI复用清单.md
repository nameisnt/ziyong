# 全局 UI 复用清单

新增或修改 App UI 时，先查本清单。除非确实是业务专属布局，否则优先复用现有全局类和组件。

## 全局样式类

| 类型               | 优先使用                                         |
| ------------------ | ------------------------------------------------ |
| 主按钮             | `.pc-primary-btn`                                |
| 普通按钮           | `.pc-soft-btn`                                   |
| 图标按钮           | `.pc-icon-btn`                                   |
| 主要图标命令       | `.pc-icon-btn.primary`                           |
| 分段按钮           | `.pc-segment-btn`                                |
| 输入框             | `.pc-field`                                      |
| 下拉框             | `.pc-select`                                     |
| 动态搜索下拉       | `SearchableCombobox.vue`                         |
| 文本域             | `.pc-area`、`.pc-area.compact`                   |
| 字段标签           | `.pc-field-label`、`.pc-field-group > span`      |
| 无框页面小节       | `.pc-page-section`                               |
| 紧凑工具栏         | `.pc-compact-toolbar`                            |
| 目录或管理行       | `.pc-list-row`                                   |
| 目录工具栏与数量   | `.pc-directory-toolbar`、`.pc-directory-count`   |
| 目录动作与列表     | `.pc-directory-actions`、`.pc-directory-list`    |
| 目录行标题与元数据 | `.pc-list-row-copy`、`.pc-list-row-meta`         |
| 行内短控件         | `.pc-inline-control-grid`、`.pc-inline-control`  |
| 独立内容卡片       | `.pc-section-card`（兼容旧页面，不作为默认分组） |
| 独立编辑或预览卡片 | `.pc-editor-card`（仅在确实需要边界时使用）      |
| 表单操作区         | `.pc-form-actions`                               |
| 详情标题行         | `.pc-detail-title-row`                           |
| 详情小按钮组       | `.pc-detail-mini-actions`、`.pc-detail-mini-btn` |

## 全局主题变量

优先使用这些变量，不要在 App 内硬编码一套主题色：

- `--pc-bg`
- `--pc-surface`
- `--pc-surface-strong`
- `--pc-soft-button-bg`
- `--pc-border`
- `--pc-text`
- `--pc-muted`
- `--pc-theme-accent`
- `--pc-primary-text`
- `--pc-danger`
- `--pc-control-radius`
- `--pc-card-radius`

注意：不要使用未纳入主题系统的临时变量，例如 `--pc-accent`、`--pc-accent-soft`、`--pc-accent-contrast`。

## 新增 UI 前检查

1. 是否已有全局类可以覆盖按钮、输入框、卡片、操作区。
2. 是否已有组件能覆盖生成、引用、空状态、检测、详情导航。
3. 是否需要抽成组件，而不是在新 App 里复制一段 HTML 和 CSS。
4. 是否使用了主题变量，而不是硬编码颜色。
5. 是否跑过 `scripts/check-ui-reuse.ps1`。

脚本默认只提醒不阻塞；需要严格失败时运行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/check-ui-reuse.ps1 -Strict
```

## 允许写局部 CSS 的情况

- App 独有的网格、图表、画布、关系图、媒体预览等布局。
- 单个业务模块的特殊排列，比如两列参数编辑器、节点折叠列表。
- 全局控件的局部间距微调，但不要重写基础按钮、输入框、卡片外观。

## 不推荐写法

不要在 App 的 scoped style 中重复定义：

```css
.pc-primary-btn { ... }
.pc-soft-btn { ... }
.pc-icon-btn { ... }
.pc-field { ... }
.pc-select { ... }
.pc-area { ... }
.pc-form-actions { ... }
```

不要出现：

```css
@media (max-width: 0px) { ... }
background: var(--pc-accent);
color: #007aff;
```

这些通常表示没有复用全局样式或主题系统。
