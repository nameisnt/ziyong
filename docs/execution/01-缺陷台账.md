## 登记规则

- 新缺陷必须写明复现证据和共同根因；根因未知时状态只能为“已发现”，不得直接修改。
- 一个批次只处理同一根因。相似外观但根因不同的缺陷分开编号。
- 修复后必须把验证命令、场景和结果写回本表，才能标为“已验证”。
- 用户真实数据、真实 API 或不可逆操作不通过本表自动授权。
