# 正则审计修复验收

## 本次范围

用户确认按推荐修复五项：导入表达式语义、首次版本选择迁移、聊天改名选择迁移、紧凑错误详情、共享弹窗键盘焦点。

- 沿用前一批条目正则、导入和提示词顺序修改，不回退工作树中的既有修改。
- 新增范围仅为上述五项及同根因的四个版本 store、阅读壳、下拉框 Escape 处理。
- 不修改真实聊天、来源正则、预设、世界书；不调用 AI；不提交或推送。
- 原有八股修复、图片脚本、用户资料和其他未跟踪文件不属于本批。
- 失效行为：导入时剥离表达式分隔符后再裁剪空白；首次重写和改名后丢失已有选择；无界错误文本挤占正文；Tab 逃出弹窗。

## 迁移边界

首次生成版本时，把无版本选择迁到唯一原始版本；新重写版本不继承。对已经出现的旧键，打开对应阅读页时按相同规则修复，不做启动全库扫描或流式内容深度监听。

只存在一个 `origin: original` 时才迁移；零个或多个原始版本均不猜测。目标键已存在时保留目标，包括显式空选择。论坛回复按同一原始版本迁移，其他条目不受影响。

聊天改名只解析 `content:` JSON 键中阅读聊天的 scope 字段，不进行子串替换，不覆盖目标选择。迁移接入既有保存与 store 重新读取流程。

旧键兼容仅用于前一批条目正则已产生的孤立选择；确认这些旧键不再存在后可移除阅读页的惰性修复，首次版本创建和改名迁移仍需保留。
