## 六、追踪规则

1. 新缺陷先进入 `01-缺陷台账.md`，再在本文绑定 Q 和批次。
2. 未有 D 编号和失败证据的 GEN、READ、CRUD 或业务 App 问题只能待复现，不得自动改码。
3. 每个实施批次结束后必须把本表的实现位置、测试 ID 和状态更新为真实结果。
4. 能力矩阵中的“不适用”必须写明业务原因，不能用来遮掩遗漏。
