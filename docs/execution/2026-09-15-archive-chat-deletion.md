# 聊天档案删除验收

## 当前需求

- 聊天详情支持单份删除；同一角色或群组内支持批量选择删除。
- 删除确认弹窗提供两个独立且默认不勾选的选项：同时删除插件内容和聊天专属配置、同时删除插件楼层备份。
- 使用酒馆原生删除流程，核对聊天消失后才清理勾选的数据；不删除角色卡或酒馆原生备份。
- 批量操作顺序执行，当前聊天最后处理；当前聊天生成中禁止删除。
- 不存在原生聊天文件的记录仍可查看保留资料，但不能再次删除原生聊天。
- 本批次不包含版本升级、发布或推送。原有世界书槽位反向同步修改保留。

## 边界

- 当前单人角色聊天删除后的原生切换分支有单元测试，尚未做真实浏览器验证；真实当前聊天切换测试使用群聊。
- 新建、编辑、导入和导出不是本批次新增功能，不改变其既有入口；删除原生聊天不可由本功能撤销。
- 不清理共享/全局配置，不删除角色卡，不自动清理酒馆原生备份。
