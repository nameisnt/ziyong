# 条目正则与提示词顺序验收

## 当前需求基线

- 阅读悬浮菜单选择本条内容的替换规则，不设置整个 App 自动应用。
- 支持版本的内置阅读页按正在查看的版本隔离；阅读聊天按聊天、楼层、候选回复隔离。
- 生成预览不自动执行酒馆显示正则，也不继承 App 的显示替换规则。
- 导入酒馆正则只复制名称、匹配式、flags、替换式，不复制深度、作用位置等执行条件，不改写酒馆来源。
- 正则库支持批量移动到分组或未分组，保留所选相对顺序，追加到目标组末尾。
- 生成输入和提示词预览统一为 App 提示词、任务模板、类型提示词、追加要求、输出格式。
- 已失效：App 全局自动替换阅读内容；任务模板放在 App 提示词之前。
- 不修改：来源聊天的酒馆 prompt 正则、预设绑定正文提取/清理、状态栏方案的正则配置。

## 数据操作边界

- 新建、编辑、删除规则沿用正则库原有入口；导入生成新 ID，不覆盖同名规则。
- 选择/解除使用已有 `usages` 存储，删除规则时沿用原有引用清理。清除选择只恢复显示，不修改原文。
- 完整备份沿用已有正则库备份字段；本次不新增单条内容导出中的规则打包机制。
- 导入错误显示错误条目/名称；读取失败可重新读取或重新选择文件，不产生半批导入。
- 未触及真实聊天、真实 API、酒馆预设/世界书写入和来源正则。工作树中原有八股修复、构建差异及未跟踪用户资料均保留。
