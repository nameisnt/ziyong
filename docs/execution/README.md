## 更新规则

1. 每批开始前只更新 `current/` 中对应状态并登记契约。
2. 批次完成后把验证证据写入 `current/`；需要保留的完整阶段历史在阶段结束时一次性切片到 `archive/`。
3. 未登记缺陷不得直接成为自动修改任务。
4. 归档正文只读，禁止把已关闭历史重新复制成当前待办。
