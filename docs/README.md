## 文档生命周期

1. 长期稳定的架构、复用和安全规则更新长期规范。
2. 当前产品或结构整改只在一个根层方案中登记。
3. 每个实施批次的实时状态只写入 `execution/`。
4. 当前方案全部关闭后移动到 `archive/plans/`，并在顶部写明归档结论。
5. 新的当前方案必须同时加入本页和安全发布候选；禁止只存在于聊天记录或本地未跟踪文件中。
